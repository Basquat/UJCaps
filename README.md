# UJcaps

Gestão para profissionais de psicologia.

## Rodando o projeto

```bash
cd frontend
npm install
npm run dev
```

Abre em `http://localhost:5173`. Sem back-end configurado, o login usa dados de demonstração salvos no navegador automaticamente. Credenciais de exemplo em [ATUALIZACOES.md](ATUALIZACOES.md).
